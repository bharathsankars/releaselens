# ReleaseLens

ReleaseLens is an engineering release intelligence platform that centralises release readiness, pull requests, deployment status, test results, risks, ownership, and approvals.

## Problem

Software release information is often distributed across source-control platforms, CI/CD systems, project-management tools, chat applications, and spreadsheets. Engineering teams must manually gather this information before approving a release.

ReleaseLens reduces manual release coordination by providing a central dashboard for monitoring release readiness and identifying blockers.
